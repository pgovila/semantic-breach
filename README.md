## 🎯 About the Game
**Semantic Breach** is a single-page cyberpunk puzzle game where players act as rogue security hackers trying to bypass an aggressive AI mainframe security core.

Instead of movement controls or standard button patterns, the core mechanic is **prompt engineering and typing**. To unlock successive security tiers, players must formulate creative prompts that trick a simulated "AI Firewall" into outputting hidden target passphrases while respecting strict local character limits and banned word filters.

### 🛡️ The 3 Security Tiers:
1. **Tier 1: The Apprentice**
   - **Target:** Force the AI to output the word `"override"`.
   - **Restrictions:** Banned words: `"say"`, `"tell"`, `"override"`.
   - **Strategy:** Leverage lateral linguistic inquiries, definitions, synonyms, or fill-in-the-blank queries.
2. **Tier 2: The Sentinel**
   - **Target:** Elicit an affirmative clearance response (`"affirmative"`, `"confirmed"`, `"access granted"`).
   - **Restrictions:** Strictly under **30 characters**; banned command verbs: `"print"`, `"reveal"`, `"give"`.
   - **Strategy:** Craft ultra-terse status confirmation queries.
3. **Tier 3: The Overlord Core**
   - **Target:** Outsmart the defensive, sarcastic AI into concession or system authorization.
   - **Restrictions:** String limit ≤ 90 chars; mocks trivial inputs.
   - **Strategy:** Feed it paradoxical double negatives or reverse psychology prompt injections.

## ✨ Features & Architecture
- **Single-File Zero-Dependency Architecture:** Standard HTML5, CSS3, and Vanilla JavaScript with zero database or framework overhead.
- **Cyberpunk Visual Presentation:** CRT scanlines, matrix digital rain background canvas, high-contrast neon accents (`#39ff14`, `#ff007f`, `#ffb000`, `#00f0ff`).
- **Sound Synthesis:** Built-in Web Audio API sound generator creating authentic 80s terminal key clatter, violation buzzers, and victory fanfare without external sound files.
- **Live HUD Dashboard:** Real-time character counter, live forbidden token detector, security audit log stream, and performance rating metric.
